# Quiz: Dependent and Independent Clauses

## Task

Create a 15-question multiple-choice grammar quiz for a 7th grader based on dependent and independent clauses taught in this YouTube video: (https://www.youtube.com/watch?v=sAo6LbCUAQo).

If you are unable to get the transcript from the given YouTube video, use the `dept-indept-clause.md` file.

## Content Coverage

Cover all of the following concepts with a mix of question types:

- Identifying whether a given clause is independent or dependent
- Identifying the subject and verb within a clause
- Choosing the correct subordinating conjunction or relative pronoun to complete a sentence
- Combining an independent and a dependent clause into one complete sentence
- Spotting a hidden verb inside a contraction (e.g., "I'm" = "I am")
- Recognizing a dependent clause standing alone as a sentence fragment

Distribute questions across:

- **Independent clauses**
- **Dependent clauses**
- **Subordinating conjunctions** — because, although, while, unless, since
- **Relative pronouns** — that, which, who
- **Combining clauses** into complete sentences
- **Fragments**

## Formatting Requirements

- Print-friendly and ink-saving: no background colors, no tables, plain black text, Arial font, US Letter page size
- Each question should have four options labeled a) b) c) d)
- Distribute the correct answers evenly between a, b, c, d options
- Header should include the title, source video credit, grade level, and a line for Name / Date / Score
- Include an answer key on a separate page showing the correct letter and a one-sentence rule-based explanation for every question
- Every page should have a title at the top and a page number at the bottom, formatted as current page of total pages (e.g. "1 of 10")
- Export as a `.docx` file
