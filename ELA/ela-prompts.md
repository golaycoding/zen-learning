# ELA Prompts

A collection of reusable AI prompts for 7th grade English Language Arts worksheets and writing review.

---

## 1. Reading Comprehension Worksheet Generator

> Swap in the topic and paste this prompt whenever you need a new worksheet.

**Prompt:**

I need a reading comprehension worksheet to improve my 7th grader's reading and writing skills. Please create the following and export as a `.docx` file.

**Topic:** `[INSERT TOPIC HERE]`

### Worksheet Contents

- **Reading Passage** — Write an original ~1,000-word informational passage on the topic above. Write at Grade 7 level — clear, engaging, and educational.
- **10 Multiple Choice Questions** — Mix factual recall AND inference-based questions. Each question must have its own independent a) b) c) d) options — never continue lettering sequentially across questions (no e, f, g, etc.).
- **Summary Writing Task** — Ask the student to write a ~200-word summary. Include bullet-point scaffolding hints of the key points to cover so the student knows where to start. Do NOT leave a blank writing space in the document — it wastes paper when printing.
- **Answer Key** — At the end of the document, include the correct answer for each multiple choice question with a brief explanation, plus a rubric or guide for scoring the summary.

### Format Requirements _(print-friendly to save ink)_

- No background colors on headers or anywhere else
- No tables
- Plain black text, Arial font, US Letter page size
- Students write answers on a separate sheet — do not print answer boxes in the document
- Export as a `.docx` file

## 2. Student Writing Review

> Paste the student's writing into the prompt below and export the results.

**Prompt:**

Please review the writing sample below from my 7th grader and export the results as a `.docx` file.

**Student's Writing:** `[PASTE STUDENT'S WRITING HERE]`

### Review Structure

**Part 1 — Annotated Essay**
Copy the student's full writing and mark all errors inline:

- Spelling mistakes: highlight the wrong word in **red**, then write the correct spelling in **green** immediately after it
- Grammar mistakes: same — wrong in red, correction in green
- Sentence structure issues: same — problem in red, corrected version in green

**Part 2 — What the Student Did Well**
List 3–5 specific things the student did well (word choice, ideas, structure, etc.)

**Part 3 — Key Areas to Improve**
List the most important patterns to work on, grouped by type (spelling, grammar, sentence structure). Keep it encouraging and specific.

**Part 4 — Model Rewrite**
Write a full, polished version of the same essay at a strong Grade 7 level. Keep the student's original ideas and topic — just improve the language, structure, and flow.

### Format Requirements _(print-friendly to save ink)_

- No background colors
- No tables
- Plain black text (except red errors and green corrections), Arial font, US Letter page size
- Export as a `.docx` file

## 3. Punctuation Quiz Generator

> Based on the 13 basic punctuation rules from [Sparkle English on YouTube](https://www.youtube.com/watch?v=zVu-XvULZNg) — https://www.youtube.com/watch?v=zVu-XvULZNg

**Prompt:**

Create a 20-question multiple-choice punctuation quiz for a 7th grader based on the 13 basic punctuation rules taught in this YouTube video: [Sparkle English – 13 Basic Punctuation Rules](https://www.youtube.com/watch?v=zVu-XvULZNg) (https://www.youtube.com/watch?v=zVu-XvULZNg).

### Quiz Coverage

The quiz should cover all 13 rules with a mix of question types:

- Identifying errors
- Choosing correct punctuation
- Fill-in-the-blank
- Multi-error spotting

Distribute questions across these rules: periods, capitalization (sentences and proper nouns), apostrophes (plurals, possession, contractions), question marks, exclamation marks, commas (lists and FANBOYS), semicolons, colons, and hyphens (compound adjectives and compound numbers).

### Format Requirements _(print-friendly to save ink)_

- No background colors
- No tables
- Plain black text, Arial font, US Letter page size
- Each question has four options labeled a) b) c) d)
- Header includes: title, source video credit, grade level, and a line for Name / Date / Score
- Answer key on a separate page showing the correct letter and a one-sentence rule-based explanation for every question
- Export as a `.docx` file
