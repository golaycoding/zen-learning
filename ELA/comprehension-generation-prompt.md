## 1. Reading Comprehension Worksheet Generator

**Prompt:**

I need a reading comprehension worksheet to improve my 9th grader's reading and writing skills. Please create the following and export as a `.docx` file.

**Topic:** `[INSERT TOPIC HERE]`

### Worksheet Contents

- **Reading Passage** — Write an original ~1,500-word informational passage on the topic above. Write at Grade 9 level — clear, engaging, and educational.
- **10 Multiple Choice Questions** — Mix factual recall AND inference-based questions. Each question must have its own independent a) b) c) d) options — never continue lettering sequentially across questions (no e, f, g, etc.). Distribute the correct answers evenly between a, b, c, d options. Earlier all correct answers were concentrated at b.
- **Summary Writing Task** — Ask the student to write a ~200-word summary. Include bullet-point scaffolding hints of the key points to cover so the student knows where to start. Do NOT leave a blank writing space in the document — it wastes paper when printing.
- **Answer Key** — At the end of the document, include the correct answer for each multiple choice question with a brief explanation, plus a rubric or guide for scoring the summary.

### Grammar Rules

- **Avoid filler/crutch words** — do not use words like actually, basically, very, really, just, simply, in fact, essentially, certainly, definitely, quite, truly. Vary sentence openers and avoid leaning on the same intensifier or filler word more than once or twice in the entire document.
- **Vocabulary** — Use 5+ bolded 9th-grade vocabulary words.Include a concise definition in parentheses after each word. Right before the answer key write these vocabulary with their meanings.

### Format Requirements _(print-friendly to save ink)_

- No background colors on headers or anywhere else
- No tables
- Plain black text, Arial font, US Letter page size
- Students write answers on a separate sheet — do not print answer boxes in the document
- Export as a `.docx` file
- At top of every page should have a title and the bottom should have page number. The page number should be current page no of total page number for e.g. 1 of 10.
