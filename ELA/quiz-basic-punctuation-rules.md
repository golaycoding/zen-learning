# Quiz: Basic Punctuation Rules

## Task

Create a 20-question multiple-choice punctuation quiz for a 7th grader based on the 13 basic punctuation rules taught in this YouTube video: [Sparkle English – 13 Basic Punctuation Rules](https://www.youtube.com/watch?v=zVu-XvULZNg).

If you are unable to get the transcript from the given YouTube video, use the `basic-punctuation-rules.md` file.

## Content Coverage

Cover all 13 rules with a mix of question types:

- Identifying errors
- Choosing correct punctuation
- Fill-in-the-blank
- Multi-error spotting

Distribute questions across:

- **Periods**
- **Capitalization** — sentences and proper nouns
- **Apostrophes** — plurals, possession, contractions
- **Question marks**
- **Exclamation marks**
- **Commas** — lists and FANBOYS
- **Semicolons**
- **Colons**
- **Hyphens** — compound adjectives and compound numbers

## Formatting Requirements

- Print-friendly and ink-saving: no background colors, no tables, plain black text, Arial font, US Letter page size
- Each question should have four options labeled a) b) c) d)
- Distribute the correct answers evenly between a, b, c, d options (earlier all correct answers were concentrated at b)
- Header should include the title, source video credit, grade level, and a line for Name / Date / Score
- Include an answer key on a separate page showing the correct letter and a one-sentence rule-based explanation for every question
- Every page should have a title at the top and a page number at the bottom, formatted as current page of total pages (e.g. "1 of 10")
- Export as a `.docx` file
